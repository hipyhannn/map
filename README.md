# Acumil Auto Maps

Web BLE companion untuk mengirim data navigasi dan frame peta `128x95` ke perangkat `Acumil-Maps`.

## Cara Pakai
1. Buka halaman GitHub Pages menggunakan browser yang mendukung **Web Bluetooth** (seperti Google Chrome di Android/PC).
2. Aktifkan Bluetooth & Lokasi/GPS.
3. Klik **1. Sambung BLE**, pilih `Acumil-Maps`, lalu klik **2. Mulai Maps**.
